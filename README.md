# zanevka newsbot: контекст проекта

## Цель проекта

**zanevka newsbot** — Python-проект для автоматизации подготовки и публикации новостей из входящих писем в WordPress с использованием данных и медиаматериалов из VK.

Основной pipeline:

```text
почта -> .eml -> парсинг текста/ссылок/изображений -> VK -> подготовка контента -> WordPress -> cleanup
```

Ошибка при обработке одной новости не должна останавливать обработку следующих писем. Временные `.eml` и извлечённые изображения должны очищаться после каждой итерации, в том числе при ошибке.

## Основные части

- `main.py` — orchestration основного pipeline.
- `eml_parser.py` — разбор `.eml` и извлечение содержимого/вложений.
- `eml_links.py` — поиск и обработка ссылок и VK-объектов.
- VK-модули — работа с VK API, видео, вложениями и preview.
- WordPress-модули — подготовка и публикация контента через WordPress API.
- `wp_probe.py` — диагностический скрипт для WordPress API.
- `config.py` — локальная конфигурация; секреты не должны попадать в Git.
- `downloaded_eml/` и `extracted_images/` — временные данные обработки.

Подробные границы ответственности модулей описаны в `ARCHITECTURE.md`.

## Разработка

GitHub — canonical repository проекта. Перед изменением кода следует ориентироваться на актуальное состояние репозитория, а не на старый контекст чатов.

Рабочая среда — Windows / Python 3.13. Проект развивается небольшими проверяемыми изменениями.
