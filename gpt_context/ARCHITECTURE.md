# zanevka newsbot Architecture

Краткая карта архитектуры проекта. Обновлять при изменении границ ответственности модулей.

## Общий поток

EML -> вложения и ссылки -> сборка новостей из DOCX -> привязка изображений/VK -> загрузка медиа -> публикация в WordPress.

## Основные модули

- `main.py` — orchestration: связывает этапы обработки.
- `eml_parser.py` / `eml_links.py` — письмо, вложения и ссылки.
- `news_parser.py` — формирование структуры новости.
- `image_manager.py` — изображения и загрузка медиа.
- `vk_video.py` — данные и preview VK.
- `wordpress.py` — взаимодействие с WordPress.

## Правила изменений

1. Предпочитать минимальные локальные изменения широкому рефакторингу.
2. Не менять контракты между модулями без отдельного решения.
3. Новую ответственность сначала размещать в существующем подходящем модуле.
4. После архитектурного изменения обновлять этот файл и при необходимости `DECISIONS.md`.
